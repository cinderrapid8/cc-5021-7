# 机械角色动画演示器 — 闭环约束求解说明

本展项在原有**树状机构直接正向求值**之外，新增了**闭合连杆约束求解器**。
树状机构（无 `constraints`）的代码路径完全不变；只有携带闭环约束的机构才进入
有限迭代求解。

## 运行

```bash
npm test          # headless 自检：smoke + 17 项解析核对 + 渲染检查
npm run serve     # http://localhost:8123 浏览器打开 index.html
```

无构建步骤、无外部依赖，所有数学（含 SVD）均在 `js/` 内实现。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `js/lineq.js` | 单侧 Jacobi SVD、最小二乘/阻尼最小二乘，输出秩与零空间维数 |
| `js/solver.js` | 闭环求解器：有限差分 Newton + LM 阻尼、步长限制、多起点回退、完整诊断 |
| `js/kinematics.js` | FK 内核（支持关节值覆盖）、四杆 Freudenstein 与 2R 逆解解析参照 |
| `js/rig.js` | 约束模型 `rig.constraints`、节点 `driven` 标记、四个耦合样例 |
| `js/closure.js` | 闭环面板：约束编辑、逐次迭代残差、失败帧导出/一键复现 |
| `js/renderer.js` | 闭合连杆虚线绘制，按残差绿/红着色，自由关节「自由」标记 |

## 模型约定

- 层级仍是一棵树；闭环只通过 `rig.constraints` 表达，不引入层级循环。
- 约束类型：
  - `coincident` 销轴重合：`axes` 选择参与的世界轴（平面机构用 `['x','y']`）。
  - `distance` 定距约束：两端锚点保持指定距离。
- 锚点 `offsetA/offsetB` 定义在各自节点的关节局部坐标系中。
- 节点 `driven: true`（默认）= 驱动关节，值只来自时间曲线，**求解器只读**；
  `driven: false` 且非 fixed = 自由关节，是求解未知量。固定关节不能作为未知量。

## 求解器行为（对应验收点）

1. **有限迭代 + 真实残差**：中心差分雅可比 + SVD 解阻尼正规方程，每次迭代的
   残差范数、最大分量、秩、零空间、λ、步长、是否接受都显示在「闭环求解」页。
2. **驱动值不可篡改**：驱动关节只取曲线+限制策略；全驱动时只能核验残差，
   不相容则状态置 `inconsistent` 并保留真实误差，不会改输入凑零。
3. **过约束**（方程 > 未知量）：相容时残差归零，不相容时给最小二乘姿态并明示
   「过约束方程组不相容」，残差保持非零。
4. **自由度不足**（未知量 > 方程）：采用最小范数解，零空间维数 = 未知量−方程数，
   面板明确提示内部自由度。
5. **多解分支**：连续播放沿用上一帧解做热启动以保持分支；热启动落入错误盆地时
   多起点回退，并提示可能切换分支。手动拖动时间轴会清除热启动种子。
6. **奇异/死点**：雅可比数值秩下降会标记 singular；每帧步长被限制
   （转动 0.5 rad、移动 0.25 m），播放时自动分子步并在失败时减半步长重试一次；
   仍失败则**暂停播放、解释原因并记录失败帧**，不会跳过坏区间。
7. **失败帧**：自动保留最近 20 帧，含时间、状态、完整迭代日志、种子和当时的 rig，
   可单帧导出或打包导出 JSON；面板「复现」按钮直接载入该 rig 与时间点。

## 耦合样例（工具栏第二组按钮）

| 预设 | 机构 | 用途 |
| --- | --- | --- |
| 四杆闭环 | 曲柄摇杆（a=.35 b=1 c=.9 d=1.1，Grashof） | 全周转动对照 Freudenstein 解析解 |
| 双支链末端 | 两支链共用末端，支链2 两关节全自由 | 多解分支与 2R 逆解析核验 |
| 过约束冲突 | 四杆再加一条冲突定距约束 | 残差不可消除、驱动值不被修改 |
| 死点演示 | 摇杆驱动，正弦扫过并越过摆角极限 95.7°–143.8° | 可达范围、死点暂停、失败帧导出 |

## 建议核验流程（连杆极限 + 驱动反向）

1. 打开「四杆闭环」，在「闭环求解」页观察残差在 ~1e-9 m 收敛；「解析核对」页
   第 9 项给出与解析公式的逐点姿态误差。
2. 把倍速设为负值（时间倒放），姿态沿原分支逆向恢复（第 14 项自动核验）。
3. 打开「死点演示」播放：摇杆进入 95.7°–143.8° 区间外时自动暂停，状态栏与面板
   给出不可达/奇异解释，失败帧出现在面板底部，可导出或点「复现」。
4. 打开「过约束冲突」：红色虚线标出闭合误差，残差恒非零，驱动关节数值与曲线
   完全一致（第 11 项自动核验）。
5. 在属性面板把任一转动关节取消「驱动关节」勾选，它即变为自由未知量，树中出现
   「自由」标记；全部关节保持驱动时求解器只做残差核验。
